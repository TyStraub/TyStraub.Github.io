Meraki Proximity Dashboard

Recreates Cisco Meraki's built-in Location Analytics after the feature was removed during the platform's Scanning-API transition. Uses existing Meraki access-point infrastructure to harvest client RSSI data, then reconstructs device proximity and how long each device lingered near an access point. A Flask dashboard handles logging, review, and interactive analysis, and every device is cross-referenced against PacketFence to resolve its registered owner.

Friendship Lamp

An interactive IoT device built on an ESP32, housed in a custom enclosure I designed and 3D printed. The lamps work in pairs, a tap on the display changes the colors of an attached ARGB LED array on both devices. Messages appear on the display, pulled from a Github Gist so they can be changed without reflashing. Both lamps work anywhere with a WiFi connection.
